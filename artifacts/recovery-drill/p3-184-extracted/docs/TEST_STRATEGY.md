# 测试策略

## 测试分层

### 单元测试

覆盖纯 Python 逻辑，不依赖 WPS 或 COM。

- 结构化响应模型
- 错误码和验证状态
- 阶段任务过滤
- ProgID 探测逻辑的可注入 resolver 分支

### 集成测试

依赖 Windows、pywin32 和本机 WPS。

- COM ProgID 解析
- 启动 WPS 组件
- 打开、保存副本、关闭
- 表格公式写入与真实计算
- 导出 PDF/HTML

### 端到端测试

模拟 Agent 调用流程。

- 检查环境
- 制定步骤
- dry-run
- 带请求 ID 执行
- 保存副本
- 验证并输出报告

## 测试资产

- 最小文字文档: 段落、标题、表格、书签
- 最小表格文档: 多字母列、公式、日期、空值、中文
- 最小演示文档: 占位符、文本框、图片
- 转换样例: docx/xlsx/pptx 到 PDF/HTML

## 验收门槛

- 所有纯逻辑单元测试必须通过。
- COM 集成测试必须标注 WPS 版本、ProgID、后端和失败原因。
- 修改类测试必须验证备份存在。
- 转换类测试必须记录已知损失，不能只给成功/失败。
