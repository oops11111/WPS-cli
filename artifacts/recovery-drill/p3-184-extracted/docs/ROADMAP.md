# WPS AI Agent CLI 后续开发路线图

## 阶段目标

### Phase 0 技术调研与可行性验证

目标是在真实 Windows + WPS 环境下确认核心假设是否成立，产出可行性报告和版本矩阵。

交付物:

- WPS 版本、ProgID、COM 注册与可用性矩阵
- 最小 COM 原型: 启动、打开、保存副本、关闭
- 表格公式写入、真实计算、原始值与显示值核对样例
- ExportAsFixedFormat 和 SaveAs2 的实际可用性与损失记录
- HTML 视觉优先转换基线
- 风险清单和进入 Phase 1 的准入结论

### Phase 1 MVP CLI

目标是形成可被 Agent 稳定调用的最小可运行版本。

交付物:

- 公共能力: 能力查询、连接、打开、列出、保存副本、关闭
- 稳定 document_id、请求 ID、幂等保护、任务状态查询
- 修改前强制备份和基础恢复路径
- WPS 文字、表格、演示三组件核心读写
- 基础格式转换矩阵和批量报告
- dry-run 预览
- 结构化 JSON 输入输出、错误码、验证结果
- 单元测试、集成测试样例和端到端 Agent 流程测试

### Phase 2 Agent 可用版本

目标是从能用升级到好用且可规模化。

交付物:

- 常驻会话与多文档并行
- MCP 与 CLI 共用核心逻辑
- 长任务进度流、可中断设计、资源回收
- HTML 三模式: 视觉优先、可编辑优先、受控往返
- 结构化日志、执行轨迹、本地诊断命令
- 批量目录处理和逐文件状态报告

### Phase 3 生产就绪版本

目标是成为 Windows 上 WPS 自动化的可靠基础设施。

交付物:

- 跨组件转换和高级能力验证
- 更强备份恢复、事务边界和审计日志
- 自动化回归测试套件
- 真实 Agent 端到端评测流水线
- 生态扩展评估

## 阶段准入规则

- 先验证，再实现。
- 每项能力必须有对应测试和可机器解析的结果。
- 兼容性、精度、成功率只基于实测记录。
- 修改操作没有备份和验证结果时不得进入可用功能集。
